A device on the US path can only reach the internet through vpnwifi-gw: if that path fails it loses internet access rather than falling back to KPN. It keeps local network access (AirPlay, HomeKit, casting) but cannot use services on Atlantis itself. IPv6 is blocked for it. Data counts IP traffic through the US path only (WireGuard overhead excluded), refreshed whenever this page loads and every 30 seconds on Atlantis; months follow Amsterdam time. The device list and persistent 23:00 reset timer are maintained in ansible/00-atlantis/device-egress.yml.
