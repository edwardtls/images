Operational contract

How the factory works

Access and ownership

Registration creates a pending account with no Factory access. An administrator separately grants cluster operations and security visibility. Cluster users can see and operate only clusters, jobs, logs and repositories associated with their own Keycloak identity.

Build choices

A profile reserves one isolated subnet, DNS zone, VMID range, MetalLB range and public edge route. Only one operation can hold a profile at a time. Choose 1, 3 or 5 control planes and between 1 and 6 workers; the default is 1 control plane and 3 workers.

Versions and add-ons

Normal versions have passed a real factory smoke build. Versions marked * were discovered automatically but remain untested. Choosing one never upgrades an existing cluster. Monitoring is optional; ingress, certificate management, Argo CD and a public test application are part of acceptance.

TTL and data

The default TTL is 24 hours. On expiry, deletion removes compute, DNS, routes, deploy keys, kubeconfig, NFS paths and Ceph pool/client, then checks for residuals. Data retention is intentionally an administrator-only exception.

Failure recovery

Preflight rejects capacity, DNS, registry and storage problems before mutation. If a later build stage fails, diagnostics are secured on Atlantis before the partial environment is rolled back. A cleanup failure remains visible instead of being treated as success.
